# Introducción

Las unidades educativas administran información académica, institucional y financiera que debe mantenerse organizada, segura y disponible. Cuando las matrículas, asistencias, calificaciones, horarios, pagos y reportes se registran en papel o en archivos separados, aparecen duplicidades, errores de transcripción, demoras y dificultades para consultar el historial de cada estudiante.

El proyecto propone un **Sistema de Gestión Académica para Colegios** bajo un modelo SaaS. La plataforma centralizará el trabajo de la institución y controlará el acceso de cada usuario mediante roles y permisos. El sistema se organiza en seis áreas principales: Superadministración, Gestión de acceso, Administración, Pedagógica, Gestión estudiantil y Finanzas.

La solución contempla una plataforma web como producto principal y deja como ampliaciones planificadas la aplicación móvil, el procesamiento de formularios escaneados mediante OCR e inteligencia artificial, las integraciones de pago y los análisis predictivos. El desarrollo se realizará de forma incremental con Scrum, diferenciando las funciones ya implementadas de aquellas que permanecen planificadas en el Product Backlog.

Este documento presenta los antecedentes, el problema, los objetivos, el alcance, los elementos del sistema, las tecnologías, los costos, los beneficios y la planificación de los sprints.
