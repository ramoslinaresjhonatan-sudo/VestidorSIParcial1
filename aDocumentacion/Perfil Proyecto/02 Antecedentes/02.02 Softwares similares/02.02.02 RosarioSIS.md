# RosarioSIS

RosarioSIS es un sistema web de gestión escolar de código abierto, desarrollado en PHP y compatible con PostgreSQL. Incluye gestión de estudiantes, asistencia, calificaciones, facturación, pagos y reportes financieros.

Su principal aporte comparativo es la integración de procesos académicos y financieros en una misma plataforma. El proyecto mantendrá esa relación, pero separará visualmente **Gestión estudiantil** de **Finanzas**: la matrícula define la inscripción académica y el pago registra la obligación o transacción económica asociada.
