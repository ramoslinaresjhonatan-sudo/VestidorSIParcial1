# Gibbon

Gibbon es una plataforma web modular de gestión escolar. Ofrece administración de estudiantes y personal, horarios, asistencia, evaluaciones, calificaciones, comunicación y recursos educativos.

Su estructura modular sirve como referencia para evitar una navegación dispersa. En este proyecto las funciones relacionadas se agrupan en áreas del menú lateral, mientras que roles y permisos determinan qué opciones puede ver y utilizar cada persona.
