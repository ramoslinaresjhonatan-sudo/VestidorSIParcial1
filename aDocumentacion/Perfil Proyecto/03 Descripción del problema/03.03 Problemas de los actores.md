# Problemas de los actores

| Actor | Problema principal |
|---|---|
| Directivos | No disponen de información consolidada para decidir y responder a requerimientos. |
| Administrativos | Repiten registros, buscan documentos físicos y elaboran reportes manualmente. |
| Docentes | Dedican tiempo a consolidar asistencia y notas en lugar de actividades pedagógicas. |
| Estudiantes | Reciben tarde sus resultados, horarios o avisos. |
| Padres o tutores | Deben acudir a la institución para conocer el avance académico o el estado de pagos. |
| Superadministrador | Necesita controlar qué instituciones acceden al SaaS, durante cuánto tiempo y con qué permisos. |
