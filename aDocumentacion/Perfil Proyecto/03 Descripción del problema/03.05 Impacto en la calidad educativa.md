# Impacto en la calidad educativa

La gestión fragmentada reduce el tiempo disponible para la enseñanza, retrasa la detección de inasistencias o bajo rendimiento y limita la participación de las familias. También dificulta comparar resultados entre periodos y planificar acciones de mejora.

Centralizar los datos no mejora por sí sola el aprendizaje, pero proporciona información oportuna para que directivos y docentes puedan intervenir, organizar recursos y realizar seguimiento con mayor precisión.
