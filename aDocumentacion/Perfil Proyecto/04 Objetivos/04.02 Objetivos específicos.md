# Objetivos específicos

1. Identificar los requisitos funcionales y no funcionales con los actores de una unidad educativa.
2. Diseñar una arquitectura SaaS modular con separación entre frontend, API y base de datos.
3. Implementar autenticación, usuarios, roles y permisos para controlar el acceso a las funciones.
4. Diseñar la administración de planes, costos, duración, límites, permisos y suscripciones por institución.
5. Implementar progresivamente los módulos de Administración, Pedagógica, Gestión estudiantil y Finanzas.
6. Modelar los procesos mediante casos de uso, actividades, secuencias, clases, componentes y despliegue.
7. Generar reportes académicos y financieros con filtros y permisos según el rol.
8. Preparar la lectura de formularios escaneados con OCR y revisión humana antes de registrar los datos.
9. Aplicar pruebas unitarias, de integración y aceptación para verificar seguridad y funcionamiento.
10. Organizar el desarrollo con Scrum en entregas incrementales de dos semanas.
