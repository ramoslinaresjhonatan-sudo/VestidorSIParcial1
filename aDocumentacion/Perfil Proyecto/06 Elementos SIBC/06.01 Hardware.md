# Hardware

El sistema requiere infraestructura para alojar la aplicación y dispositivos para acceder a ella:

- servidor cloud o servidor Linux para frontend, API y servicios auxiliares;
- servidor de base de datos PostgreSQL;
- computadoras o tabletas para dirección, Secretaría, docentes y Caja;
- teléfonos inteligentes para las futuras funciones móviles;
- escáner o cámara con resolución suficiente para digitalizar formularios;
- red local y conexión a internet estable;
- almacenamiento de respaldos separado del entorno principal.

La capacidad definitiva se calculará según instituciones, usuarios concurrentes, estudiantes y volumen de documentos.
