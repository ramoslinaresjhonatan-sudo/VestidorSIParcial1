# Software

El software se divide en los siguientes componentes:

- interfaz web desarrollada con React;
- API REST desarrollada con Django REST Framework;
- autenticación JWT, roles y permisos;
- base de datos PostgreSQL;
- módulos SaaS, administrativos, pedagógicos, estudiantiles y financieros;
- servicio futuro para trabajos asíncronos y OCR;
- herramientas de control de versiones, pruebas, documentación y despliegue.

La comunicación entre la interfaz y el backend se realizará mediante HTTPS y respuestas JSON.
