# Datos

Los grupos principales de datos serán:

| Área | Datos principales |
|---|---|
| Superadministración | Planes, precios, moneda, duración, límites, módulos, suscripciones y vigencia. |
| Acceso | Usuarios, roles, permisos, estados y sesiones. |
| Administración | Institución, personal, ambientes y calendario. |
| Pedagógica | Gestión, periodos, niveles, cursos, paralelos, materias, asignaciones, horarios, planificación, asistencia y calificaciones. |
| Estudiantil | Estudiantes, datos de contacto y tutor, matrículas, retiros y traslados. |
| Finanzas | Conceptos de cobro, mensualidades, pagos, comprobantes, caja y movimientos. |
| Soporte | Documentos, bitácoras, notificaciones y parámetros del sistema. |

Todas las entidades operativas deberán relacionarse con la institución correspondiente para evitar cruces de datos entre clientes del SaaS.
