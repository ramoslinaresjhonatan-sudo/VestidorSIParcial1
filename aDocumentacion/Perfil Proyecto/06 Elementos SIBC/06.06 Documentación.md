# Documentación

La documentación del proyecto se organizará en tres grupos:

1. **Desarrollo:** requisitos, Product Backlog, historias, casos de uso, arquitectura, modelo de datos, API y decisiones técnicas.
2. **Operación:** instalación, variables de entorno, despliegue, monitoreo, copias de seguridad y restauración.
3. **Usuario:** manuales por rol, guías de los módulos, preguntas frecuentes y procedimientos de soporte.

Cada sprint actualizará su planificación, backlog, diseño, implementación, pruebas, revisión y retrospectiva. No se registrarán como terminadas funciones que todavía sean solo pantallas iniciales o propuestas.
