# Proceso de desarrollo

Se aplicará Scrum con un Sprint 0 de preparación y cuatro sprints de desarrollo de dos semanas. Cada ciclo incluirá planificación, desarrollo, pruebas, revisión del incremento y retrospectiva.

El trabajo se priorizará por dependencia: primero acceso y control SaaS; luego configuración institucional; después operaciones académicas y estudiantiles; finalmente finanzas y reportes. Las historias pendientes conservarán ese estado hasta cumplir sus criterios de aceptación.
