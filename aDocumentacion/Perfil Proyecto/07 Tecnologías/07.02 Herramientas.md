# Herramientas

- **Frontend:** React 19, Vite 8, React Router, TanStack Query, Axios, React Hook Form y Zod.
- **Backend:** Python, Django 5.2 y Django REST Framework.
- **Seguridad de API:** Simple JWT y CORS configurado.
- **Datos:** PostgreSQL y Psycopg.
- **Pruebas:** Pytest, Pytest-Django, ESLint y compilación de producción con Vite.
- **Modelado:** diagramas UML y Draw.io.
- **Repositorio:** Git y GitHub.
- **Planificación:** tablero Scrum/Kanban por definir entre las herramientas del equipo.
- **Móvil:** Flutter, planificado para una fase posterior.

Las versiones indicadas corresponden al proyecto actual y sustituyen las versiones generales mencionadas inicialmente en el PDF.
