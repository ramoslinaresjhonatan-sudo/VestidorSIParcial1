# Despliegue

El despliegue objetivo separará la interfaz web, la API Django y PostgreSQL. El entorno de producción utilizará HTTPS, variables de entorno para secretos, almacenamiento persistente y respaldos programados.

Antes de seleccionar Azure, AWS u otro proveedor se realizará una comparación de costo, disponibilidad regional, almacenamiento, respaldo y facilidad de mantenimiento. El documento original menciona más de un proveedor; por ello la plataforma definitiva se mantiene **por seleccionar**.

Se prevén ambientes independientes para desarrollo, pruebas y producción, además de un proceso automatizado de validación antes de publicar cambios.
