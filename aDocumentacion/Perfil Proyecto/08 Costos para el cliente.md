# Costos para el cliente

El costo dependerá del modelo de despliegue, la cantidad de estudiantes, los módulos contratados y las integraciones externas. El documento base propone estos valores únicamente como **referencia preliminar**:

| Concepto | SaaS | Instalación propia |
|---|---:|---:|
| Costo base | Bs 300/mes, hasta 500 estudiantes | Bs 10.000 inicial |
| Estudiante adicional | Bs 5/mes | No aplica |
| Infraestructura inicial | Incluida | Bs 5.000–8.000 |
| Capacitación inicial | Bs 1.000 | Bs 2.000 |
| Soporte y actualizaciones | Incluido | Bs 1.000–1.500/año |
| Copia de seguridad | Incluida | Bs 500/año |
| Internet | A cargo de la institución | A cargo de la institución |

Estos montos no constituyen todavía una cotización. Deben validarse con costos reales de infraestructura, soporte, impuestos, pasarelas de pago y OCR antes de aprobar los planes comerciales.

El superadministrador podrá crear varios planes sin modificar código. Cada plan guardará nombre, costo, moneda, periodo de cobro, duración, límites, módulos, permisos, estado y observaciones. La suscripción registrará qué plan tiene cada institución, sus fechas y su estado de renovación.
