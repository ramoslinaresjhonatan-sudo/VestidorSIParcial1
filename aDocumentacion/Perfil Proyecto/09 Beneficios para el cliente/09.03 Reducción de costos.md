# Reducción de costos

La digitalización puede reducir el uso de papel, tinta, archivadores y espacio físico, además del trabajo requerido para reconstruir o comparar registros dispersos. El modelo SaaS distribuye el costo de infraestructura, mantenimiento y actualización mediante una suscripción.

El ahorro real deberá medirse durante un piloto comparando materiales utilizados, horas de trabajo, incidencias y tiempo de elaboración de reportes antes y después de implementar el sistema.
