# Infraestructura tecnológica

- Repositorio Git para frontend, backend y documentación.
- Frontend web React servido como aplicación estática.
- API REST Django ejecutada en un servidor de aplicaciones.
- PostgreSQL como base de datos de producción.
- Entornos separados de desarrollo, pruebas y producción.
- HTTPS, variables de entorno y administración segura de secretos.
- Almacenamiento persistente para documentos y respaldos.
- Integración continua para lint, compilación y pruebas automatizadas.

El proveedor cloud se seleccionará después de comparar costos y requisitos. No se considera confirmada una plataforma solo porque aparezca como ejemplo en el PDF original.
