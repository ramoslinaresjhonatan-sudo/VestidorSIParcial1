# Historias de usuario y casos de uso

| ID | Historia resumida | Actor | Resultado esperado |
|---|---|---|---|
| C15 | Como coordinador quiero asignar docentes para cubrir materias y cursos. | Coordinación | Carga docente válida por periodo. |
| C16 | Como coordinador quiero construir horarios para organizar las clases sin choques. | Coordinación | Horario validado por curso, docente y ambiente. |
| C17 | Como docente quiero registrar mi planificación para controlar el avance curricular. | Docente | Plan y avance vinculados a materia y periodo. |
| C18 | Como docente quiero registrar asistencia para dar seguimiento a mis estudiantes. | Docente | Asistencia por fecha con estados y justificación. |
| C19 | Como docente quiero registrar calificaciones para evaluar el rendimiento. | Docente | Notas validadas y resultados calculados. |
| C22 | Como Secretaría quiero matricular a un estudiante para incorporarlo a una gestión y paralelo. | Secretaría | Matrícula activa y cupo actualizado. |
| C23 | Como Secretaría quiero registrar retiros o traslados para conservar el historial. | Secretaría | Cambio de estado trazable sin borrar la matrícula. |
