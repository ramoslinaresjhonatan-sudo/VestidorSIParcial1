# Historias de usuario y casos de uso

| ID | Historia resumida | Actor | Resultado esperado |
|---|---|---|---|
| C20 | Como directivo quiero reportes académicos para analizar asistencia y rendimiento. | Directivo | Información filtrada y consolidada. |
| C24 | Como administrador quiero configurar conceptos de cobro para definir obligaciones. | Administrador | Conceptos con monto, frecuencia y alcance. |
| C25 | Como cajero quiero registrar pagos para actualizar el saldo del estudiante. | Caja | Pago trazable con comprobante. |
| C26 | Como administrador quiero generar mensualidades para controlar vencimientos y deudas. | Administrador | Obligaciones periódicas y estados de cuenta. |
| C27 | Como cajero quiero abrir y cerrar caja para conciliar los movimientos del día. | Caja | Saldo esperado, contado y diferencia registrada. |
| C28 | Como directivo quiero reportes financieros para conocer recaudación y pendientes. | Directivo | Reportes por fecha, concepto, método y estado. |

C25–C27 son procesos transaccionales: requieren validación de saldos, estados, permisos y auditoría, no solo crear o editar registros.
