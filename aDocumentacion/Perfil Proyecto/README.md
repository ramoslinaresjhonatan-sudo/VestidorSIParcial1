# Perfil del proyecto

Esta carpeta organiza el contenido del perfil del proyecto según el índice del documento.

El contenido fue redactado a partir de `PERFIL PROYECTO.pdf` y actualizado con la estructura modular acordada para el sistema. Las funciones futuras se identifican como **planificadas** y no se presentan como implementadas.

## Estructura principal

1. Introducción
2. Antecedentes
3. Descripción del problema
4. Objetivos
5. Alcance
6. Elementos del SIBC
7. Tecnologías
8. Costos para el cliente
9. Beneficios para el cliente
10. Sprints
11. Bibliografía
12. Anexos

El contenido íntegro del capítulo 5 también está disponible en [05 Alcance completo.md](05%20Alcance/05%20Alcance%20completo.md). Los archivos organizados por inciso dentro de `05 Alcance` se conservan como fuentes editables.

La sección `10 Sprints` contiene Sprint 0 y los cuatro sprints de desarrollo. Cada sprint de desarrollo tiene carpetas para planificación, objetivos, actividades, historias de usuario y casos de uso, diagramas, implementación, pruebas, Daily Scrum, revisión y retrospectiva.

## Módulos del producto

1. Superadministración: Planes y Suscripciones.
2. Gestión de acceso: Usuarios, Roles y Permisos.
3. Administración: Institución, Personal, Ambientes y Calendario institucional.
4. Pedagógica: configuración académica, cursos, materias, docentes, horarios, planificación, asistencia, calificaciones y reportes.
5. Gestión estudiantil: Estudiantes, Matrículas, Retiros y Traslados.
6. Finanzas: Conceptos de cobro, Pagos, Mensualidades, Caja y Reportes financieros.
